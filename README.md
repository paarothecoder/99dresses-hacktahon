# 99DRESSES ,Hyperlocal Fashion Exchange Platform

## 📌 Project Overview
99DRESSES is a peer-to-peer fashion exchange platform designed to solve logistics and marketplace inefficiencies in clothing exchange systems.  

The platform enables users to exchange clothing locally, reducing shipping costs and improving availability of desirable fashion items through an algorithm-driven recommendation system.

The goal is to create a friction-less hyperlocal marketplace where users can discover, exchange, and communicate easily.

---

## 🚀 Features Implemented

### Core Features
- User listings for clothing exchange for money
- Hyperlocal matching of users
- Algorithm-based clothing recommendations
- Wishlist for saving desired items
- Category-based search
- User profile and listings management
- Chat system for exchange coordination
- Match-based browsing similar to swipe interfaces

### UX & Design Features
- Simple and intuitive interface
- Familiar swipe-based browsing experience
- Optimized for dense social environments such as colleges

## 🏗 Technical Architecture

### Frontend
- HTML
- CSS
- JavaScript

### Backend
- Django

### Database
- sqlLite / postgresql 

### Architecture Flow
1. Users upload clothing listings.
2. Matching algorithm suggests items.
3. Users connect and coordinate exchanges.
4. Exchange occurs locally to minimize logistics cost.

The system optimizes connections based on user proximity, solving shipping and delivery cost issues.

---

## 🧠 Problem Analysis & Innovation

Earlier clothing exchange startups failed due to:

- High logistics and shipping costs
- Weak virtual currency systems
- Technical debt and unstable platforms
- Marketplace liquidity issues

### Our Solution
- Hyperlocal exchange remove the shipping costs.
- Simple app flow improves user adoption.
- Recommendation algorithm improves item discoverability.
- Users choose exchange locations themselves.
